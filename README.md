# Weather Diary

**Автор:** Санников Вадим

## Описание программы

Приложение «Дневник погоды» позволяет вести учёт погодных наблюдений: добавлять записи с датой, температурой, описанием и наличием осадков. Данные сохраняются в файл JSON. Доступна фильтрация по дате и температуре.

## Требования

- Python 3.x
- Библиотеки: tkinter, tkcalendar

## Установка и запуск

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/theskittlesk3d/k3333d.git
   ```
2. Перейдите в папку проекта:
   ```
   cd k3333d
   ```
3. Установите зависимости:
   ```
   pip install -r requirements.txt  # если есть файл requirements.txt
   ```
4. Запустите приложение:
   ```
   python kod.py
   ```

## Использование

- На вкладке «Добавить запись» введите данные и нажмите «Добавить запись».
- На вкладке «Фильтровать записи» укажите дату или температуру для поиска.
- Все записи отображаются в списке внизу окна.
